# Stock Portfolio Tracker

## Project Description

A Python-based Stock Portfolio Tracker that helps users manage their stock investments.

## Features

- View available stock prices
- Add stocks to portfolio
- Track stock quantities
- Calculate total portfolio value

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run Stock.py.
